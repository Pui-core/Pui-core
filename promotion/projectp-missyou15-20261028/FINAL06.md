- 画像の寄りは 5–7 フレームで着地し、その後は静止に近く保つ。文字は 2 フレームで見える濃度へ入り、約 6 フレームで着地。全カットを同じ揺れや移動で埋めていない。
- 上部の余白へ短いストリークを 3 回、完成の瞬間へ濃度 14% から消える暖色の光を 1 回。重要な UI と文を覆う全編点滅は使用していない。
- 日記の全景→2つのスタンプ→短文→全景へ切り替え、完成した内容を読み取る時間を残す。
- 最後の声は完成ページから先に入り、締めのカードは 8.63 秒開始。カードの滞在を約 2.9 秒へ短縮し、フォロー案内は 9.13 秒から表示。

## 実素材と確認

実録・名前と文面の編集範囲・相手送信済みの fixture・外部通信 0 の出典は FINAL05.md と同じ。選択後の封ボタンや完成状態を編集で見せるが、収録していない押下や開封アニメーションは作っていない。動画の「開発版・架空例（名前と文面を編集）」、相手は送信済みという条件を保持。

- PhotoCraft の v06 表紙を保存・PNG 出力・再読込。EffectCraft を F の保存先から再読込して ProRes 346 フレームへ実描画。FilmCraft の両原本を F から再読込して MP4 を実出力し、offlineMedia は空。
- 最終両 MP4 を全デコードして exit 0。全秒シート、1.8–5.8 秒の 10 fps シート、ありがとう寄り、完成、末尾 11.4 秒を目視。独立担当も実 MP4 抽出画と SHA を照合し、重要 UI・相手送信済み・2つのスタンプ・開発版・締めに必須の画面不備なしと判定。
- 最終 AAC の声・効果音版は -22.4 LUFS / true peak -4.4 dBFS、BGM 版は -23.7 LUFS / true peak -4.3 dBFS。声の最後の有声は -45 dB 判定で 10.197 秒まであり、終端へ約 1.34 秒の余白を保持。これは全編の主観試聴を意味しない。

全編の直接試聴、TikTok 内のネイティブ音源指定と実表示の安全域は未確認。今回の投稿・予約はしていない。owner の v05 創作評価を、これらの確認や公開済みという意味へ読み替えない。開発版を配布中と断定せず、未確認の Store リンクを追加しない。

## 原本と再生成

`PROJECTP136_ROOT` に v06 制作領域を指定し、次の順で実行する。

1. `prepare-speed06.mjs`：v05 の安全な素材を複製、声の位置変更と別効果音 / BGM トラックの制作。
2. `photo-speed06.mjs`：PhotoCraft 表紙。
3. `picture-speed06.mjs`：9 カットと演出を EffectCraft 原本へ保存。
4. `render-speed06.mjs`：EffectCraft の ProRes と FilmCraft 最大 3 トラックで両版を出力。
5. `qa-speed06.mjs`：実 MP4 の全デコード、形式、音、画像シート。

元素材は v05 のローカル原本と同じ内容である。NAS の動画しか残っていないと推測して素材を再生成せず、既存の F の制作原本と依存素材を使う。
