# ぷいのキネティック動画5本

SNS動画自体の収益・作品認知・依頼獲得を目的にした、各64秒のオリジナルシリーズ。

- JavaScriptの3問
- Web導線の改善
- コピペ作業の自動化
- 同じ操作の3つの編集
- 制作あるある短編

制作・運用方針は[日本語の方針書](制作-%230084SNS動画5本の運用方針.md)。台本と投稿文はsourceに保存。完成動画・ネイティブ原本とQAは最終検証後に追記する。

実制作: kinetic-short-video、EffectCraft 0.14.0、FilmCraft 0.10.0、builtin image_gen、VOICEVOX:四国めたん、自作音楽。外部楽曲・別案件のキャラは使わない。
