# ぷいの制作を追う5本

完成品の一覧だけでなく、実際の試作の不具合、作り直した判断、音を聴き比べて選ぶ過程を見せる。日ごとに、本人の幅・失敗と修正・ゲームの一場面・道具の好み・曲の制作という題材を変える。

| 動画 | 見せるもの |
| --- | --- |
| 01 | 部品の分解から作品の幅へ。楽曲制作ではサビ約3.4秒。 |
| 02 | 剣の柄端が台座に隠れた実試作と修正。実ChatGPTの問いとBlenderの原本確認も差し込む。 |
| 03 | 自作ゲームの一歩と跳躍を、主人公へ追従して見る。 |
| 04 | 初版の道具から、自分の好みに寄せて作り直す判断。 |
| 05 | medicateの実際の調整前後を同じ区間で聴き比べ、本人が選んだ音へ。 |

遷移は最初の約0.18秒で着地し、続く対象の動きと分ける。文字を読ませる場面では止める。終わりは画像の領域と作者名・締め文を分離する。途中に入る楽曲にはフェードを付ける。

Firefoxの実会話は、本人から画面録画による収集を許可された制作関連部分だけを使う。未取得の会話を再現画面として作らない。制作メモの要旨・実音声から描いた波形・実ゲーム映像を区別する。

medicateの曲・歌・MVは本人制作と確認済み。旧版を保持し、本版は別フォルダに保存。技術検査と抽出画像の目視、全編の実時間視聴・試聴、ownerの表現採用、公開後の結果は別の確認事項である。バズや収益・受注を保証する記録にはしない。
