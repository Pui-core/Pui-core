# おさゆ初ビンゴ：アグレッシブ版 V2

ownerからの「画面遷移・追従を強く。モデルも指さしやピースで動かしてよい」という品質指摘を受けた改稿。[タスク #83](https://github.com/Pui-core/-/issues/83) に紐づく。初稿は別フォルダに保存したまま、この版を制作する。

## 変えたところ

- 150BPMの1拍0.4秒にカットを同期。22秒を11場面へ構成し、0.8〜1.6秒の切返し、急な寄り引き、横パン、回転からの着地を組み合わせた。
- キャラクターに**指さし・ピースと笑顔**を追加。ポーズを切り替えながら、スケール・位置・傾きを動かす。手足の連続的な骨格アニメーションやLive2D化とは異なる、2Dポーズ素材による演出。
- 文字・キャラクター・盤面をNullへ親子付けし、同じカメラに追従。盤面では「初見さん20人」から「おはさゆ20回」を追って、全体へ戻る。
- 方向のあるワイプとモデルのモーションブラーを追加。文字は移動後も読めるよう、文字自体のブラーを外した。
- オリジナルの強いビートと3.2秒のドロップを制作。19.2秒以降は日時と案内を読むために音と動きを落ち着かせた。

方向性は引き続き「初見もひと言から参加できるVライバー」。冒頭の「おさゆに何て言わせる？」から、一列ごとのリクエストセリフへつなげる。元の写真投稿で確認した9目標と、一列ごとのセリフ・全マス達成で歌ってみたの**サビを後日投稿**という条件は維持する。日時はowner確認済みの **11/24 22:00**。
