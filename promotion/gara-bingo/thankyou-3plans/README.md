## 構成

- 0–2秒: ほぼ無音。「はじめてのビンゴ企画で…」「みんな、ありがとう。」
- 2秒から: 曲と同時に空の盤面。3つの注目マスを順に拡大して追い、約4.92秒で盤面全体へ戻る。
- 約6–14秒: 初見さん・同事務所凸・セリフリクエストを文字のハイライトで再構成。見出し→4・6・8のカウンターへ寄り、それぞれの場面の終わりで全体へ復帰。
- 約14–17秒: 8マスの盤面へ戻り、最後の1マスへ大きく寄る。達成直前に9マス全体を見せる。
- 約17–21秒: 9/9達成。大きなBINGO、桜色の花びらと紙吹雪。完成した小盤面へ164%で追従してから「全マス達成!!」へ戻る。
- 約21–25秒: 曲を下げ、感謝の言葉→「歌ってみたサビ 後日公開！」へ追従。24.25秒で全体表示へ戻して締める。

達成の事実は今回のowner依頼を根拠とします。マスが埋まる順序とハイライトは演出上の再構成で、実配信の切り抜きや達成時刻・順序の再現ではありません。セリフや本人の発言を捏造した音声は使いません。

## 素材と確認

既存V4の元JPEGと通常の外周背景透過PNGをそのまま使用。人物は全25秒で位置730,1290・幅380px・高さ760px、回転0・不透明度100%、親・アニメーション・効果・マスクなしで固定します。AIにキャラクター画像を送信せず、別のキャラ未読込原本で文字と動きを確認します。盤面を追う親と見出し・下部補足を分け、固定の表示窓で寄り中の盤面を収めます。

1080×1920/30fps/750フレーム、両MP4の全デコード、音声ストリーム、最終AACの音量、人物固定構造、可逆描画の不透明コア、編集原本再読込・再描画、納品コピーSHAを検査します。追従は静的な文字bboxだけで判断せず、native原本のカメラ値と注目点、キャラ未読込の全場面・主要切替・追従途中/着地/全体復帰の連続画像を照合します。実行結果は各案の `qa/` と総合 `validation.json` を正とし、実施前に成功したとは扱いません。人間の全編試聴・実機TikTok画面・ownerによる創作承認は別の確認項目です。

## 再制作

Windows版EffectCraft/FilmCraft/FFmpeg/ImageMagickとWSL Node.jsが必要です。素材rootは `OSAYU_THANKYOU_ROOT` で変更できます。

```sh
node pipeline.mjs prepare
node pipeline.mjs previews
node pipeline.mjs motion-review
node pipeline.mjs tracking-review
node pipeline.mjs render
node pipeline.mjs verify
node audit.mjs /home/pui/Videos/Osayu-Bingo/2026-10-25/thankyou-tracking-v2 --native
node tracking-audit.mjs /home/pui/Videos/Osayu-Bingo/2026-10-25/thankyou-tracking-v2
node package.mjs
```

制作root: `/home/pui/Videos/Osayu-Bingo/2026-10-25/thankyou-tracking-v2`。コード管理: Pui-core/Pui-core。Issue無効のため管理窓口 Pui-core/-#91 を使います。前版は同窓口 #90、[PR #12](https://github.com/Pui-core/Pui-core/pull/12) で管理しています。
