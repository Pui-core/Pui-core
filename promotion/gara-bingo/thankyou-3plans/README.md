## 構成

- 0–2秒: ほぼ無音。「はじめてのビンゴ企画で…」「みんな、ありがとう。」
- 2秒から: 曲と同時に空の盤面。拍に合わせて3マスが埋まる。
- 約6–14秒: 初見さん・同事務所凸・セリフリクエストを文字のハイライトで再構成。カウンターは4→6→8へ。
- 約14–17秒: 8マスの盤面へ戻り、「あと、ひとマス。」
- 約17–21秒: 9/9達成。大きなBINGO、桜色の花びらと紙吹雪。
- 約21–25秒: 曲を下げ、「みんな本当にありがとう♡」「歌ってみたサビ 後日公開！」。最後まで読める状態を保つ。

達成の事実は今回のowner依頼を根拠とします。マスが埋まる順序とハイライトは演出上の再構成で、実配信の切り抜きや達成時刻・順序の再現ではありません。セリフや本人の発言を捏造した音声は使いません。

## 納品

各案の `*-reference.mp4` は今回ownerが許可した公開試聴を使った私用比較版。`*-tiktok-silent.mp4` は音声トラック0で、TikTok内の音源を後付けする版です。曲の版・区間・合わせ方は [音源後付けガイド](音源後付けガイド.md) を参照してください。

EffectCraft本番とキャラ未読込原本、FilmCraftの映像・音声別トラック原本、ソース、素材、投稿文、QA記録を版付きで保持します。素材・試聴音源・人物入り出力は公開Gitに保存しません。SNSへの投稿は行いません。

## 素材と確認

既存V4の元JPEGと通常の外周背景透過PNGをそのまま使用。人物は全25秒で位置730,1290・幅380px・高さ760px、回転0・不透明度100%、親・アニメーション・効果・マスクなしで固定します。AIにキャラクター画像を送信せず、別のキャラ未読込原本で文字と動きを確認します。

1080×1920/30fps/750フレーム、両MP4の全デコード、音声ストリーム、最終AACの音量、人物固定構造、可逆描画の不透明コア、編集原本再読込・再描画、納品コピーSHAを検査します。実行結果は各案の `qa/` と総合 `validation.json` を正とし、実施前に成功したとは扱いません。人間の全編試聴・実機TikTok画面・ownerによる創作承認は別の確認項目です。

## 再制作

Windows版EffectCraft/FilmCraft/FFmpeg/ImageMagickとWSL Node.jsが必要です。素材rootは `OSAYU_THANKYOU_ROOT` で変更できます。

```sh
node pipeline.mjs prepare
node pipeline.mjs previews
node pipeline.mjs render
node pipeline.mjs verify
node audit.mjs /home/pui/Videos/Osayu-Bingo/2026-10-25/thankyou-3plans --native
node package.mjs
```

コード管理: Pui-core/Pui-core。Issue無効のため前回と同じ管理窓口 Pui-core/-#90 を使います。
