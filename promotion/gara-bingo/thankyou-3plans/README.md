## 構成

- 0–0.8秒：「みんな！」。画面全体が入る短い導入。
- 0.8–2秒：「ありがとう♡」。2枚目の感謝カードへ切り替える。
- 2秒から：曲と同時に空のビンゴ盤面。3つのマスを順に追い、盤面全体へ戻る。
- 約6–14秒：初見さん・同事務所凸・セリフリクエストの見出しを約1秒ずつ表示し、ワイプで4・6・8の数字ページへ切り替えて画面ごと寄る。
- 約14–17秒：最後の1マスへ寄り、完成直前に盤面全体へ戻る。
- 17秒から：全マス達成。「BINGO!」から完成した9マスへ追従し、達成の言葉へ戻る。
- 約21秒から：感謝のページ、続いて歌ってみたサビの予告ページ。24.33秒から全体表示で締める。

達成の事実は今回のowner依頼を根拠とします。マスが埋まる順序とハイライトは演出上の再構成です。実配信の切り抜きや達成時刻・順序の再現ではありません。本人の発言を作った音声は使用しません。

## 素材と全画面追従

今回のowner明示により、立ち絵も全体カメラの子として画面と一緒に動かします。元JPEGと既存の通常透過PNGは保持し、人物レイヤー自身の位置730,1290・幅380px・高さ760px、回転0、不透明度100%は変更しません。人物固有のキー・効果・マスク・画像生成は加えていません。

背景は人物を含まない新規の紙背景です。背景・文字・図形・人物・全画面ワイプの全レイヤーを `WHOLE FRAME CAMERA` の直接の子にします。局所ビューポートや画面に固定されたHUDは使用しません。

背景の配色根拠と生成指示は [背景生成プロンプト](背景生成プロンプト.md) に記録しています。

AIで見る検品原本には人物画像を読み込まず、同じカメラの子になった灰色矩形を代わりに置きます。灰色矩形・紙背景・文字が一緒に移動すること、注目対象の着地と全体復帰、最後の予告が読めることを確認します。人物入り原本・動画・PNGはAIビューアへ渡しません。

## 再制作

Windows版EffectCraft/FilmCraft/FFmpeg/ImageMagickとWSL Node.jsが必要です。制作rootは `OSAYU_THANKYOU_ROOT` で変更できます。同梱版を再制作する場合は `editable/source` で実行し、`OSAYU_THANKYOU_ROOT` にその親の `editable` の絶対パスを指定します。root配下の `media`・`audio-preview` と背景manifestが必要です。旧版フォルダへの依存はありません。

```sh
node pipeline.mjs prepare
node pipeline.mjs previews
node pipeline.mjs whole-review
node wholeframe-audit.mjs "${OSAYU_THANKYOU_ROOT:-/home/pui/Videos/Osayu-Bingo/2026-10-25/thankyou-wholeframe-v3}"
node pipeline.mjs render
node pipeline.mjs verify
node package.mjs
```

`package` は現在の原本SHAに対応する `qa/visual-review.json` を必要とします。原本を作り直した場合は、人物未読込の新しいプレビューを目視確認して記録を更新してから実行します。過去の目視判定を新しい原本へ流用しません。
