# おさゆ初ビンゴ：文字＋元の立ち絵固定版 V3

ownerが示した利用規約を受け、元のJPEGを通常の編集ソフトへ固定配置し、文字だけを動かす22秒の告知へ作り直した。タスクは[Issue #83](https://github.com/Pui-core/-/issues/83)。

## 今回の素材の扱い

- 元の `立ち絵.jpg` をバイト一致でコピー。画像ファイルを加工せず、全体を縦横比どおりに表示する。背景除去、切抜き、色替え、変形、ポーズ/表情差分、画像エフェクトは使わない。
- 画像の位置・サイズ・回転・透明度は22秒間一定。親カメラ、マスク、モーションブラー、3D化、リグ、自動演技を付けない。
- 原画像やキャラが映る動画・画像を、AI生成/画像解析へ入力しない。動かす文字を作るプロジェクトと、元JPEGを置く納品プロジェクトを分ける。
- AIでレイアウトを確認するのは、画像Footageが0件と検証した `text-only.ecproj` 由来の文字プレビューだけ。固定領域は灰色の長方形で示し、そこにキャラクター画像は読み込まない。
- 原画像の未改変と固定配置はSHA・保存した原本構造・最終動画のROI数値比較で確認。キャラ入りの最終画面をAIで目視確認したとは報告しない。

owner指定を今回の制作手段へ反映した記録。前版の生成差分や加工素材はV3へ同梱しない。

## 集客の見せ方

方向性は「初見もひと言から参加できるビンゴ配信」。冒頭の「おさゆに、何て言わせる？」でリクエストセリフの楽しみを見せ、参加のハードルを「おはさゆ」のひと言へ落とす。白背景に濃い文字、ティールとピンクの強調を使い、文字の左右からの入り・大小・短い着地を150BPMに合わせる。

立ち絵の固定表示領域は1080×1920中の `x=500,y=735,width=390,height=780`。主見出しはその上、説明と行動案内は左に置く。重要文字を立ち絵へ重ねない。

## 納品と再生成

Windows納品先は `F:\Users\pui\Documents\gara\bingo-1124-v3`。動画は `osayu-bingo-v3-1124.mp4`。

`editable/projects/` に固定画像入り原本・文字のみ原本・FilmCraft原本、`media/` に未改変JPEGとオリジナルBGM・無音映像マスター、`source/` に再生成コード、`qa/` に数値検品と文字のみプレビューを同梱する。キャラ入りの確認画像は `qa/local-only/` に隔離し、AIツールへ渡さない。

```bash
node produce.mjs prepare
node produce.mjs previews

```

BGMは前版で制作したオリジナルの150BPM音源を再利用。`audio.mjs` は必要時の同じ音源の再生成用で、人物画像を扱わない。本人の声は未使用。
