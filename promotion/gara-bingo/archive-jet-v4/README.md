## 動画の選び方

- `*-voice-only.mp4`：**配信音声版・追加BGMなし**。TikTokで曲を後付けする版です。本人の声を残すため音声トラックがあります。
- `*-reference.mp4`：配信音声と上表の公開試聴曲を合わせた私用比較版です。

`voice-only` は元配信のBGM・ギフトSEまで除いた純粋なボーカル音源を意味しません。元配信の音は残る場合があります。無音版へ置き換えて感謝の声を消さないでください。合わせ方は [音源後付けガイド](音源後付けガイド.md) に記録しています。

尺、曲の入り、達成、感謝、予告の時刻は `edit-manifest.json` が正本です。各shotの映像区間と各voiceの発話区間を分け、3案で同じ実配信素材を使います。切り抜きの順序・スタンプ・達成カウントは編集上の再構成であり、実際の達成順序の再現とは扱いません。歌ってみたの約束は「サビを後日投稿」の範囲です。架空の本人声・生成ポーズ・表情変更は使いません。

## 素材と時刻

元資料は `F:\Users\pui\Documents\gara\配信アーカイブ\20261024_アーカイブ.mp4`。元動画は保持し、通常のFFmpegとネイティブ編集ソフトで選んだ区間だけを編集します。動画は720×1280・可変フレームレート、音声には先頭の遅れと途中のPTSギャップがあります。音声担当が作るcontainer 0秒起点の同期WAVを、発話検索と音声切り出しの共通基準にします。ASRの候補時刻へ先頭遅れを二重加算しません。

選んだ映像は720×1280/CFR30・音声なし・素材時刻0秒からの短いMP4へ変換し、配信音声は48kHzの別WAVへ切り出します。`qa/extraction.json` は元動画SHA、source区間、CFRフレーム数、選択素材SHA、音声timelineとmanifestのSHAを記録します。ASRは候補検索であり、字幕の正確さ・話者・発話の自然な切れ目を確認したことと区別します。

紙背景はV3で生成済みの人物を含まないPNGを通常コピーして再利用します。今回、新しい画像生成は行っていません。V3制作時に元ビンゴの非AI OCR・RGB数値解析で確認した淡いラベンダー、水色、薄桃を参照した背景です。リボン・星・紙片はV3で加えた演出です。背景PNGと `media/background-manifest.json` をSHAで照合します。

[背景生成プロンプト](背景生成プロンプト.md) はV3制作時の記録をそのまま同梱したものです。

## AIへ人物映像を渡さない検品

AIが見る原本にはアーカイブ動画・人物画像をimportしません。映像枠だけを同じ720×1280の灰色矩形へ置き換え、字幕・背景・図形・全体カメラは本番と一致させます。枠の中心原点と動画の左上原点によるanchor差、灰色枠の線、source種別だけを明示的な差分として許可します。

`audit.mjs` は全レイヤーの共通parent、main/previewの共通構造、枠の位置・拡大率・時間・コア矩形、nativeカメラキー、背景の画面4隅カバーを検査します。背景検査は全camera keyと中間時刻のサンプルであり、全フレーム目視ではありません。preview内の画像・動画・音声参照は、承認済みの紙背景1枚以外を拒否します。

人物を含む本番原本・最終動画・切り抜きPNGはAIビューアへ渡しません。通常ソフトの再読込・描画、全デコード、寸法・fps・尺、音声構成・最終AAC音量、素材と原本SHAを確認します。灰色枠の目視では、実配信の表情・口形・映像内容の意味・顔の収まりを確認したとは言えません。全編試聴、人物入り動画の人間による確認、TikTok実機、ownerの創作上の採用は別に記録します。

## 納品と再制作

納品先は `F:\Users\pui\Documents\gara\bingo-thankyou-archive-jet-v4-20261026`。以前の納品は保持します。3案×2動画、EffectCraft本番/人物未読込・FilmCraftの9原本、選んだclip、発話別WAV、共通の配信音声mix、各案のvoice/music別WAV、背景、試聴、ソース、選択manifest、検証記録を渡します。FilmCraftはV1=映像、A1=配信音声、A2=追加曲です。

元アーカイブ全体と長い解析用同期WAVは同梱しません。manifestと抽出記録にある元archive・同期WAVの絶対pathはローカルの出典情報です。選択済み素材でのprepare/render/verifyはそれらへ依存しません。元から切り出し直すextractには元動画と同期WAVが必要です。

Windows版EffectCraft/FilmCraft/FFmpeg/FFprobe/ImageMagick、WSL Node.jsが必要です。同梱版では `editable/source` を開き、`OSAYU_ARCHIVE_ROOT` に親の `editable` の絶対pathを設定します。`media`、`audio-preview`、`edit-manifest.json`、`qa/extraction.json` が必要です。

```sh
node pipeline.mjs prepare
node pipeline.mjs previews
node audit.mjs "$OSAYU_ARCHIVE_ROOT"
node pipeline.mjs render
node pipeline.mjs verify
```

新しいpreviewを目視し、現在のmain/preview SHAと必須指摘の有無を `qa/visual-review.json` に記録してから梱包します。以前の原本の目視判定は流用しません。再梱包は作業rootから離れた新しい納品先を指定します。

```sh
node package.mjs /mnt/f/Users/pui/Documents/gara/bingo-thankyou-archive-jet-v4-reexport
```

素材・試聴・人物入り動画は公開Gitへ入れず、SNS投稿も行いません。コードと今回の実装はPui-core/-#101で管理します。
