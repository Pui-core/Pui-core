# Digital Horizon とv4カットの限定照合

公式Studio取得音源の私有解析票を参照し、v4のカット0.600/1.500/1.900/3.000秒を、4系統の冒頭音立ち上がり候補と比較しました。音声・PCMはGit/Fへ複製していません。曲ID、BPM69/92/138の選択、拍頭、TikTok内の使用開始位置、聴感、投稿への紐付けは未確定です。

source0秒をnative開始と仮定すると、0.600→0.6333と3.000→3.0333（各1フレーム）で4系統/4カットの平均最近傍差は59.250→44.521ms。ただしsource offset+0.050秒では32.813→41.146msへ逆転します。この平均は音楽的な拍・知覚評価・成功率ではなく、各解析が挙げた候補までの距離です。解析hop23.22msと30fpsの量子化もあり、1フレーム差を大きな改善と保証しません。

1.500秒は中域1.509秒と既に9ms差。1.900秒では低域1.858秒と中域/全帯域1.950秒が競合するため、どちらかを拍と決めて移動しません。したがって今回の判断は**v4維持・新revision再描画なし**です。Rootの未投稿stageにも触れていません。実開始区間と聴感を確認した後、必要なカットだけを実際に再編集します。

Rootは22:36 JSTに本人StudioエディタのDigital Horizonトラックと−12dB表示の保存後維持を確認しました。これは実際に聞こえるミックスや公開投稿での紐付けの証明ではありません。私有のsource0/-12dB参考mixもnativeプレビューとは区別します。

元111 payloadの3Craft/F検査と最終MP4は不変更。この別appendは数値検討と観測範囲の更新です。全編視聴/主観試聴、native source offset、曲ID/拍、実投稿、成長指標の未確認をPASSにしません。
