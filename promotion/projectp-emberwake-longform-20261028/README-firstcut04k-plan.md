**620秒は紙上の予定で、実MP4の実尺や質を証明しない。** `source/firstcut04k-paper-edit.json` に既存音声の実長・各枠の残り・0.2秒の最低間隔を記録している。新しい説明8句は合成してWAV実長を測定、旧声との合計は517.487秒。残る102.513秒には句間と比較画面の予定を含むが、最低句間を引いても約83.71秒が未割当で、意味のある10分成立には不十分。主観試聴も未実施。空白による尺稼ぎはしない。

短押し／長押し、2話の通常／分岐、保存原画比較と1〜13話の実収録、固定版の計測資料は保有している。合流の両映像、章背景の特徴、手帳・台詞と音声の一致はそれぞれ元収録から再確認してから使う。現04jの2:26.4–2:34.4「二つの経路が同じ足場へ」の音声に対し、元編集表の主映像は第10話の収録であり、後段の部分修正を含む最終画面の対応は未確定。04jの当該区間を第2話の実証には流用しない。

04jの8:38.6–8:53.8「公園の柵とベンチ」「雨の軒と閉じた窓」も問題。対応する第3話16秒・第5話20秒の元収録画像、および両話の複数時点を確認したが、その説明対象を視認できなかった。全収録に存在しないと断定はできないものの、実映像と説明の対応は未証明で、04jを公開できない理由に追加する。別版は採用せず、確認できた月・建物の輪郭・背景色・柱の説明へ差し替える。第8話の額縁状、第10話の歯車状の線、第13話45秒のアーチは個別画像で確認。

比較図は記録の数値を実値として示し、現行版の短押し／長押し動画を旧版と修正版の映像比較と偽らない。原画の再表示を旧版の実プレイと扱わない。ゲーム内の背景変化が記憶喪失に連動すると主張しない。元資料: `production/product/docs/verification-jump-response.md`、`detail64-rendering.md`、実収録receipt。

## 制作へ進む条件

各区間の原データと音声・字幕の一致、各比較の開始・結果、背景の該当画面を確認し、実際に使える絵と発話の尺を測る。628秒の設計枠に十分な異なる内容が入るか、映像と間の密度を点検する。成立したら別原本で3Craft編集と出力を行い、実尺600秒以上、全AV、音声頭尾、画面の読みやすさと連続視聴・主観試聴を確認する。これらが未完の間は公開しない。
